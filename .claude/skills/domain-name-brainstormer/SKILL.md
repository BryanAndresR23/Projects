# Domain Name Brainstormer

## Overview
Generate creative domain name ideas and check availability across multiple top-level domains (TLDs). Produces relevant naming suggestions tailored to your project concept.

## When to Use
- Launching a new project, product, or personal brand
- Rebranding an existing venture
- Finding alternatives when first choices are taken
- Starting a side project that needs a web presence

## Process

1. **Understand the concept** — Ask about purpose, audience, tone, and industry
2. **Generate candidates** — 10–20 name ideas across styles (descriptive, invented, metaphorical)
3. **Check availability** — Verify across .com, .io, .dev, .ai, .co, .app
4. **Filter and rank** — Short, memorable, pronounceable names first
5. **Provide alternatives** — When top choices are taken

## Quality Criteria for Domain Names

| Criterion | Guideline |
|-----------|-----------|
| Length | Under 15 characters preferred |
| Hyphens | Avoid — hard to say aloud |
| Numbers | Avoid — ambiguous (is it "4" or "four"?) |
| Pronunciation | Easy to spell when heard |
| Memorability | Unique enough to stand out |
| Availability | .com preferred for trust; .io/.dev for tech |

## TLD Selection Guide

| TLD | Best For |
|-----|----------|
| .com | Universal trust, consumer products, established brands |
| .io | Tech startups, developer tools, SaaS products |
| .dev | Developer-focused tools, open source projects |
| .ai | AI/ML products, data companies |
| .co | Startups, modern brands (shorter than .com) |
| .app | Mobile applications |
| .design | Creative agencies, design tools |

## After Brainstorming
1. Register your top 2–3 choices quickly (domains sell fast)
2. Verify social media handle availability (Twitter/X, Instagram, GitHub)
3. Check for trademark conflicts (USPTO TESS database)
4. Test names with real people in your target audience before committing

## Example Prompt
```
I'm building a tool that helps developers write better commit messages using AI.
Target: professional developers, B2B SaaS.
Tone: technical but approachable.
```

## Example Output Format
```
Primary Recommendations (.com available):
1. commitcraft.com — descriptive, memorable
2. gitwise.com — short, tech-adjacent

.io Alternatives:
3. commitai.io — direct, AI-forward
4. pushperfect.io — action-oriented

Creative Options:
5. betterpush.dev — developer-targeted TLD
6. loglab.ai — minimal, memorable
```
